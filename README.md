# MovieRoll project page

Static project website for Tencent-Hunyuan/MovieRoll.

GitHub Pages publishes the `page` branch from `/`. Videos are hosted directly in `assets/videos/`.

Edit `content.json` for metadata and media, and `app.js` for method descriptions and efficiency tables. After changing the catalog, run `python scripts/build_offline_data.py`. Preserve THIRD_PARTY.md and asset attribution.
